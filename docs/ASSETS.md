# Original asset provenance

No MU Online models, maps, textures, icons, UI, source code or music were copied. MU 99b is the gameplay benchmark only. Aurelia, Vanguard, Brom, Lyra, Sproutling, Forest Wolf, Crowns and Éter are explicit names requested for this slice. The layout and model interpretations are original.

Character, creatures, buildings, foliage, props, item meshes, effects and HUD icons are authored in src/client/art.ts, scene.ts and icons.ts. Three.js is a general rendering library. There is no imported music.

Two textures were generated with the built-in image generation tool using the imagegen skill, inspected and copied into the workspace. No generated-image home-directory path is used at runtime.

- public/assets/aurelia-cobblestone.png: original mossy weathered limestone ground albedo.
- public/assets/greenfields-meadow.png: original short grass, soil and leaf-litter terrain albedo.
